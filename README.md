DigitalDrift is a high-performance, real-time system orchestrator that utilizes event-driven microservices to optimize computational workloads.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/DigitalDrift.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

DigitalDrift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
